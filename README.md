# Micron AI Gateway demo (custom-demo-poc)

Kong AI Gateway 2.2 (hybrid, Konnect control plane) on GKE namespace `micron-aigw`, with Okta SSO, Anthropic + Bedrock (+ Foundry added live), CrowdStrike AIDR, budgets, A2A agents, MCP governance, OpenTelemetry/Grafana.
Everything here is code; secrets live only in `secrets.yaml` (git-ignored; template in `secrets.yaml.template`).

## One-command deploy (from an empty namespace)
```bash
./deploy.sh        # idempotent; ~10 min
./reset-demo.sh    # pre-demo state
demo/preflight.sh && demo/run-tests.sh
```
`deploy.sh` runs, in order: `scripts/load-secrets.sh` (k8s Secret), `kubectl apply -f k8s/*.yaml` (observability, Redis, data plane, chaos shim, MCP mocks, watcher, log-ingest, AIDR broker, agents, ingress + Google-managed cert), `scripts/dns-sync.sh`, `identity/02-okta-setup.py` and `03-okta-agents.py`, `scripts/bootstrap-vault.sh`, `scripts/apply.sh` (kongctl), `scripts/api-models.sh`, `scripts/api-openai-models.sh`, `scripts/deploy-cost-attribution.sh`, `scripts/native-budgets.sh`, `scripts/ingest-handbook.py`, `grafana/gen.py`.
Prerequisites on the laptop: kubectl (context of the shared cluster), gcloud (DNS), kongctl >= 1.20 with a Konnect PAT in `secrets.yaml` (`PAT`, `KONNECT_REGION`), python3, jq, curl, helm not needed.

## Layout
| Path | What |
|---|---|
| `konnect/10-gateway.yaml` (one set of model entities; routes `/anthropic` and `/sandbox/anthropic`) | gateway as code (auth strategy, providers, models, policies, MCP servers, agents). `konnect/lua/*.lua` are included into policies by `scripts/render.py`. |
| `konnect/budgets.json`, `cost-attribution-config.json` | budget table (watcher) and cost tags |
| `k8s/` | namespace workloads; `k8s/90-dashboards.json` is generated by `grafana/gen.py` |
| `identity/` | Okta users/groups/auth server/app (`02`), agent identities + token exchange (`03`), membership helper. `01-entra-setup.sh` = Entra attempt (groups only; user creation was denied) |
| `clients/` | Claude Code apiKeyHelper (`okta_token.py`) and launcher |
| `mocks/` | chaos shim, MCP servers, agents, budget/ops watcher, log ingest, CrowdStrike broker |
| `demo/` | one script per demo action; `run-tests.sh`, `preflight.sh`, `section8.sh` |
| `ai-cost-attribution/` | the custom streaming plugin (cost tags) published by `scripts/deploy-cost-attribution.sh` |
| `GAPS.md`, `DEMO-RUNBOOK.md`, `PRE-DEMO-CHECKLIST.md`, `TEST-REPORT.md`, `PROGRESS.md` | docs |

## Where the agents live in the Kong config
| What | Where |
|---|---|
| Agent registrations (route, auth, group ACL, logging) | `konnect/10-gateway.yaml` → `agents:` → `ticket-triage-agent` and `release-notes-agent` (type `http`, paths `/agents/<name>`, OIDC strategy `micron-oidc`, allow `Demo-Engineering`) |
| MCP servers the agents call | `konnect/10-gateway.yaml` → `mcp_servers:` → `mcp-ticketing`, `mcp-code-search`, `mcp-hr-records` (type `passthrough-listener`, group ACLs) |
| Per-agent tool limits ("user via agent" errors) | `konnect/lua/edge-guard.lua` → `AGENT_TOOLS` table (included into a policy by `scripts/render.py`) |
| Agent identities (Okta service apps, RFC 8693 token exchange) | `identity/03-okta-agents.py` |
| Agent budgets ($5/day each) | `konnect/budgets.json` and `scripts/native-budgets.sh` |
| Agent code and pods | `mocks/agents/agent.py` (one A2A app, two roles), `k8s/95-agents.yaml` (Deployments `agent-triage`, `agent-release`) |

Note that the same `agents:` list also holds `models-endpoint-*`: the per-group `GET /v1/models` endpoints are modelled as HTTP agents (as in Kong/kong-claude-ai-gateway), not real agents.

## Not in this repo
- `secrets.yaml` (copy `secrets.yaml.template`), `.state/` (gateway ID, data-plane cert, Okta state): created by `deploy.sh`.
- `ai-cost-attribution/` (custom streaming plugin used by `scripts/deploy-cost-attribution.sh`): Kong-internal, clone `KongHQ-SE/ai-cost-attribution` into `./ai-cost-attribution`.
- Generated demo files (`data/pdfs`, `data/large`): `data/generate.py` / `data/make-large.py` recreate them.
